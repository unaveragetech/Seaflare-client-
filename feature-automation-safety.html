Feature — Automation Safety Net

A bad fight shouldn't cost you the session.

Panic Mode, Auto Log, and Auto Relog watch health, damage, and nearby players so unattended automation has a real exit condition, not just a start condition.

Panic Mode

One key disables every module, the RTP mapper, and the bundled combat client's modules together, then restores exactly what it disabled on release.

Auto Log

Disconnects on low health, a damage burst, or a player getting too close — then disarms itself so rejoining doesn't log you straight back out.

Auto Relog

Disconnects and reconnects to a server you choose after a delay, capped at a set number of relogs per session.

How it works

Relog can't live inside a module — so it doesn't.

A module's tick loop stops the instant the world goes null, which is exactly the state a reconnect spends nearly all of its life in. A module can start a logout. It can never be the thing that finishes one.

Session control runs outside the module system

Auto Relog's reconnect logic runs from the raw client tick, not from inside the module manager. It holds the target server's address in a static field, because the game clears its own current-server entry as part of disconnecting — by the time the reconnect timer fires, that information would otherwise already be gone. If you rejoin by hand before the timer runs out, it cancels itself cleanly and leaves your manual choice alone.

  • Chosen destination — reconnect to a specific server, or back to whichever one you were just on.
  • Address validated up front — a bad address disarms the module instead of stranding you at the title screen.

Grace windows, against re-trigger loops

Both trigger modules ignore every armed condition for a configurable window right after a fresh world is entered. Without it, a condition that's still true the moment you rejoin — low health that hasn't regenerated yet, a player still standing where they were — fires again instantly, and what should be a safety net turns into a join/quit loop instead.

Panic Mode restores exactly what it disabled

Toggling panic doesn't just flip every module off — it records which ones were actually on first. Releasing panic restores that exact set. Nothing that was already off gets turned on, and nothing extra gets left running because the release logic assumed a default state instead of the real one.
